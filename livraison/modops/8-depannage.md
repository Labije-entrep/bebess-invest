# Dépannage en une page

*Labije Cab, fiche pratique du gestionnaire. Une page.*

| Symptôme | À vérifier |
| --- | --- |
| **Le client ne reçoit pas son lien** | 1. Ses courriers indésirables. 2. L'adresse exacte (l'écran répond toujours « un lien est envoyé », même si l'adresse est inconnue). 3. Que son accès existe et n'est pas suspendu. 4. Il peut demander **10 liens par heure** au plus : qu'il patiente. |
| **Le lien « ne marche plus »** | Il dure **15 minutes** et ne sert **qu'une fois**. Redemander un lien. |
| **On redemande un lien trop souvent** | La session dure 30 jours **par appareil et par navigateur** ; changer d'appareil, vider les cookies ou se déconnecter la perd. Après un changement d'adresse de connexion du cabinet, tout le monde doit se reconnecter une fois. |
| **La performance affiche « Non calculable »** | Il faut **deux arrêtés à deux dates différentes**. Ce n'est pas une erreur. |
| **Le tableau de bord signale un écart** | L'historique et les enveloppes divergent : refaites un **Nouvel arrêté** pour les réaligner. |
| **Une entrée du menu manque** | Elle dépend du module souscrit et de votre rôle (associé, collaborateur, lecture). |
| **Mon site ne se met pas à jour** | Attendez une minute après « Enregistrer », rechargez la page. Un champ « Description (balise meta) » ne s'affiche jamais : c'est normal. |
| **La page Notes est vide** | Aucune note n'est **publiée** : une note en brouillon est invisible. |
| **Un nouvel accès affiche un montant** | Il dépasse les accès inclus : voir « Mes accès et mon abonnement ». |

## Si rien ne résout
Notez **ce que vous faisiez, le message affiché et l'heure**, puis écrivez à votre interlocuteur. Les incidents techniques sont aussi consultés de notre côté.
