# Publier une note de marché

*Labije Cab, fiche pratique du gestionnaire. Une page. Actus : module Pilotage. Notes : module Site vitrine.*

## 1. Saisir l'actu du jour
Menu **Actus** : une fiche par jour. Le bloc **« Chiffres »** se remplit seul à partir des cours du marché. Vous saisissez le **résumé**, les **faits**, ce qu'il y a **« à dire aux clients »**, les mots-clés et la source. Vous pouvez coller le texte d'origine tel quel. Enregistrez.

## 2. En faire une note
Depuis l'actu enregistrée, créez une **note de marché**. Vous pouvez aussi créer une note à la main depuis le menu **Notes**.

## 3. La rédiger
Une note est d'abord un **brouillon**, invisible du public. Rédigez son titre, son chapeau et son texte. Les intertitres se notent avec `##`, les paragraphes se séparent par une ligne vide.

## 4. La publier
Cliquez sur **« Publier »** : son statut devient « Publié » et elle apparaît sur la page **Notes** de votre site public. **« Repasser en brouillon »** la retire du site sans la supprimer.

## Bon à savoir
- Les chiffres d'une actu **ne bougent plus** une fois sa note publiée.
- Le site se met à jour en une minute environ.
- Une page Notes vide fait mauvais effet : publiez-en une ou deux avant d'ouvrir le site au public.
